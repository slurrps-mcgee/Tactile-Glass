Documentation

TactileGlass is a CSS framework that combines tactile neumorphism, frosted glass, and a hybrid of both. It is MIT licensed and published as tactileglass-css. Use this page as the source-of-truth for class names, tokens, and how the pieces compose.

Install

Package name tactileglass-css on npm.

npm install tactileglass-css

Load the compiled stylesheet from your bundler:

import 'tactileglass-css/dist/tactileglass.min.css';

Or link it from HTML:

<link rel="stylesheet" href="node_modules/tactileglass-css/dist/tactileglass.css">

Sass entry if you compile it yourself: tactileglass-css/src/scss/tactileglass.scss

Class language

Three layers, always in this order of meaning:

  • Component + material. neu-btn, glass-card, hybrid-input. The material prefix is the surface. The second word is the control.
  • Modifiers. Bootstrap-style extras that work on every material: btn-sm, btn-primary, card-interactive, nav-sticky, input-pill.
  • Utilities. Tailwind-style helpers for layout, space, shape, and surface: d-flex, p-4, rounded-squircle, morph-glass, theme-dark. 
<button class="neu-btn btn-primary btn-lg">Save</button>

<section class="glass-card card-sm p-4">...</section>

<div class="morph-hybrid rounded-squircle p-6">Custom panel</div>

Three materials

Pick one material per node. Do not stack neu-btn with glass-btn.

neu

Raised or sunken clay. Shadows come from --neu-shadow-drop and --neu-shadow-inset.

glass

Frosted acrylic. Color modifiers become translucent lenses, not solid fills.

hybrid

Glass fill sitting inside a tactile shadow. The signature TactileGlass look.

morph-neu, morph-glass, and morph-hybrid paint those surfaces onto any element without turning it into a component.

Layout and containers

container is a centered, breakpoint-growing shell (540 / 720 / 960 / 1140 / 1320). Start a shell at a later breakpoint with container-sm through container-xxl. Use container-fluid for full width with the same gutters.

Flex and grid live as utilities: d-flex, f-col, gap-3, grid-3, col-span-2.

See the container showcase for live widths.

Dark mode

Add theme-dark to <html> (or any subtree) to invert the token palette: canvas, ink, glass, and neu shadows. Use theme-light to force a light island inside a dark page. data-theme="dark" / data-theme="light" work the same way. 

<html class="theme-dark">
  ...
</html>

<section class="theme-dark p-6 rounded-lg">
  Dark island
</section>

The moon button in the navbar is a theme-toggle control. Persist the choice on document.documentElement — the docs site stores it as localStorage.tg-theme.

Tokens

Everything themable is a CSS custom property on :root. Override them in your own stylesheet after TactileGlass loads. The overrides page walks through live examples.

Token Role
--clr-primaryBrand color and focus ring
--clr-darkBody and heading ink
--clr-bgCanvas and neu surface fill
--clr-success / --clr-warning / --clr-dangerSemantic accents
--glass-bg / --glass-blur / --glass-borderGlass engine
--hybrid-bgHybrid fill sitting on neu shadows
--neu-shadow-drop / --neu-shadow-insetTactile depth
--radius-sm / --radius-md / --radius-lg / --radius-squircleRounding
--sz-1 … --sz-12Spacing scale
--font-sans / --font-display / --font-monoType families

Contribute

TactileGlass is open source under the MIT License. Issues and pull requests are welcome on GitHub. 

git clone https://github.com/slurrps-mcgee/Tactile-Glass.git
cd Tactile-Glass
npm install
npm run dev

Useful scripts:

  • npm run sass:build — compile dist/tactileglass.css
  • npm run sass:watch — rebuild on Sass changes
  • npm run serve — docs at src/docs with /dist mounted
  • npm run build — compile + minify

Source lives in src/scss: base/ tokens and mixins, components/ controls, layouts/ flex and grid, utilities/ morph, theme, spacing, and helpers.

Keep class names unambiguous: material first, then the control, then modifiers, then utilities.
