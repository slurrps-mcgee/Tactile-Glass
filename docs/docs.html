Documentation

TactileGlass is a CSS framework that combines tactile neumorphism, frosted glass, and a hybrid of both. It is MIT licensed and published as tactileglass-css. Use this page as the source-of-truth for class names, tokens, and how the pieces compose.

Install

Package name tactileglass-css on npm.

npm install tactileglass-css

Load the compiled stylesheet from your bundler:

import 'tactileglass-css/dist/tactileglass.min.css';

Or link it from HTML:

<link rel="stylesheet" href="node_modules/tactileglass-css/dist/tactileglass.css">

Sass entry if you compile it yourself: tactileglass-css/src/scss/tactileglass.scss

Class language

Compose component + style, then modifiers:

  • Component + style. tg-btn tg-neu, tg-card tg-glass-frosted, tg-select tg-hybrid. The control is generic. The style class paints it.
  • Modifiers. Bootstrap-style extras that work on every style: btn-sm, btn-primary, tg-interactive, nav-sticky, tg-neu-reverse, input-pill.
  • Utilities. Tailwind-style helpers for layout, space, and shape: d-flex, p-4, rounded-squircle, bg-white, text-white, border-none, theme-dark. Prefer style classes over morph-*; morph is the !important escape hatch. 
<button class="tg-btn tg-neu btn-primary btn-lg">Save</button>

<section class="tg-card tg-glass-frosted card-sm p-4">...</section>

<details class="tg-select tg-glass-frosted">...</details>

<div class="tg-hybrid rounded-squircle p-6">Custom panel</div>

Three styles

Pick one style per node. Do not stack tg-btn tg-neu with tg-btn tg-glass.

neu

Raised or sunken clay. Shadows come from --tg-neu-shadow-drop and --tg-neu-shadow-inset. Pair with tg-neu-reverse, tg-neu-surface, or tg-neu-inset.

glass

tg-glass for the pane; tg-glass-frosted for blur, inset glow, and edge sheen. Color modifiers become translucent lenses.

hybrid

Glass fill sitting inside a tactile shadow. The signature TactileGlass look.

Style classes paint any element. morph-neu, morph-glass-frosted, morph-hybrid-reverse, and the rest mirror that matrix with !important.

Layout and containers

container is a centered, breakpoint-growing shell (540 / 720 / 960 / 1140 / 1320). Start a shell at a later breakpoint with container-sm through container-xxl. Use container-fluid for full width with the same gutters.

Flex and grid live as utilities: d-flex, f-col, gap-3, grid-md-3, col-md-6. Infixes follow Bootstrap: p-md-8, not md:p-8. See Layout and Utilities.

See the container showcase for live widths.

Collapsible nav

Collapse is CSS-only. details.nav-collapse holds only the hamburger summary. Put .nav-links as a sibling under .tg-nav. Keep theme-toggle in .nav-end on the top row.

Below the expand breakpoint the panel is hidden until the details is open. From md (768px) up, nav-expand-md shows the links in a row and hides the toggle. Use nav-expand-lg to wait until 992px, or omit the expand class to keep the hamburger at every width. 

<header class="tg-nav tg-hybrid nav-sticky">
  <a class="nav-brand" href="/">TactileGlass.css</a>
  <div class="nav-end">
    <button type="button" class="theme-toggle" data-theme-toggle></button>
    <details class="nav-collapse nav-expand-md">
      <summary class="nav-toggle" aria-label="Menu">
        <span class="nav-toggle-bars" aria-hidden="true"></span>
      </summary>
    </details>
  </div>
  <nav class="nav-links">
    <a href="/" class="is-active">Home</a>
    <a href="/docs">Docs</a>
  </nav>
</header>

Depth modifiers stay on the parent: tg-neu-reverse, tg-neu-surface, tg-neu-inset (same suffixes on glass and hybrid). Do not put inset or surface classes on .nav-links.

Dark mode

Add theme-dark to <html> (or any subtree) to invert the token palette: canvas, ink, glass, and neu shadows. Use theme-light to force a light island inside a dark page. data-theme="dark" / data-theme="light" work the same way. 

<html class="theme-dark">
  ...
</html>

<section class="theme-dark p-6 rounded-lg">
  Dark island
</section>

The moon button in the navbar is a theme-toggle control. Persist the choice on document.documentElement — the docs site stores it as localStorage.tg-theme.

Tokens

Public API is --tg-{name} from the light map, plus structural tokens in src/scss/base/_tokens.scss. --clr-* / --glass-* stay aliases. Dark only patches ink, canvas, shadows, and glass/hybrid fills — pastels inherit. Live examples live on Customize.

Contribute

TactileGlass is open source under the MIT License. Issues and pull requests are welcome on GitHub. 

git clone https://github.com/slurrps-mcgee/Tactile-Glass.git
cd Tactile-Glass
npm install
npm run dev

Useful scripts:

  • npm run sass:build — compile dist/tactileglass.css and copy it into docs/
  • npm run sass:watch — rebuild on Sass changes
  • npm run serve — docs at docs/
  • npm run build — compile + minify

Source lives in src/scss: base/ tokens and mixins, styles/ neu/glass/hybrid, components/ controls, layouts/ container, flex, and grid, animations/ motion, utilities/ morph, theme, spacing, and color.

Keep class names unambiguous: component, then material, then modifiers, then utilities.
