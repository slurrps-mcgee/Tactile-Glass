Containers

Base container grows with the viewport (540 / 720 / 960 / 1140 / 1320). Start later with container-sm container-md container-lg container-xl container-xxl. container-fluid stays full width with the same gutters. These bands sit outside the page shell so you can see the real max-widths.

container-fluid — 100%
container-xxl — 1320px at 1400+
container-xl — 1140px at 1200+
container-lg — 960px at 992+
container-md — 720px at 768+
container-sm — 540px at 576+
container — responsive from sm through xxl
