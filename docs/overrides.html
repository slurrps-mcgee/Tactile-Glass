Overrides

TactileGlass is token-driven. You do not fork the Sass to recolor an app — reassign CSS variables on :root or on a wrapper. Tokens inherit, so a scoped class restyles every descendant control.

1. Global :root

Load TactileGlass first, then your stylesheet. Anything you set on :root replaces the default palette for the whole page. 

<link rel="stylesheet" href="tactileglass.css">
<style>
  :root {
    --clr-primary: #c084fc;
    --clr-primary-rgb: 192, 132, 252;
    --clr-bg: #c8c2d4;
    --radius-md: 12px;
  }
</style>

Keep the matching *-rgb channel in sync when you change a color. Semantic fills use rgba(var(--clr-primary-rgb), 0.15) for tints.

2. Scoped brand

A wrapper class is enough for a marketing island or a dashboard module. This block sets --clr-primary to violet; buttons, badges, and text-primary inside it follow.

.demo-aurora

badge-primary text-primary link 
.demo-aurora {
  --clr-primary: #c084fc;
  --clr-primary-rgb: 192, 132, 252;
}

3. Radius and clay

Rounding and neu shadows are tokens too. Sharpen corners with --radius-*, or retint the clay with --clr-bg plus a matching shadow pair.

Tight radii

--radius-md: 6px;
--radius-lg: 10px;

Warm clay

morph-neu-inset
--clr-bg: #d7c4b0;
--neu-shadow-drop: 8px 8px 16px #b59d86,
  -8px -8px 16px #f3e6d6;

4. Nested themes

theme-dark and theme-light are utilities, not page-only flags. Drop them on any wrapper. The navbar toggle still sets theme-dark on <html>.

theme-dark island

Canvas, ink, and shadows flip even if the page is light.

ok

theme-light island

Force the default palette inside a dark page.

5. What to override

If you want to change… Set
Brand / focus --clr-primary and --clr-primary-rgb
Page ink --clr-dark, --clr-slate
Neu clay --clr-bg plus --neu-shadow-drop / --neu-shadow-inset
Glass frost --glass-bg, --glass-blur, --glass-border, --hybrid-bg
Rounding --radius-sm, --radius-md, --radius-lg, --radius-squircle
Type --font-sans, --font-display, --fs-base
Dark palette Prefer theme-dark; or override the same tokens under .theme-dark

Full names are listed in the docs token table and in src/scss/base/_tokens.scss.
