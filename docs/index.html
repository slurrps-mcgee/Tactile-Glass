CSS framework

TactileGlass

A utility-first and component-based CSS framework. Every control ships in three materials — neu (tactile extrusion), glass (frosted acrylic), and hybrid (both) — then you stack Bootstrap-style modifiers and layout utilities on top.

Install from npm Read the docs Browse components

Install

Package name tactileglass-css on npm.

npm install tactileglass-css

Then load the compiled stylesheet:

import 'tactileglass-css/dist/tactileglass.min.css';

Sass entry: tactileglass-css/src/scss/tactileglass.scss

Class language

  • neu-btn glass-card hybrid-input

    Components. Material first, then the control name.

  • btn-sm btn-primary card-interactive

    Modifiers. Same names as Bootstrap, work on every material.

  • morph-glass rounded-squircle p-4

    Utilities. Paint a raw element, or tweak layout and shape.

Three materials

Pick one material per component. Do not mix neu-btn with glass-btn on the same node.

neu

Raised or sunken clay. Use for high-frequency controls that should feel physical.

glass

Frosted pane. Color modifiers become translucent lenses instead of solid fills.

hybrid

Glass fill sitting inside a tactile shadow. The signature TactileGlass look.

Morph any element

morph-* utilities apply a surface to a plain div, section, or pre. They are not components — no padding or type is baked in.

morph-neu

Raised tactile slab.

morph-neu-inset

Sunken basin.

morph-glass

Frosted acrylic.

morph-hybrid

Glass + extrusion.

morph-flat

No depth, hairline border.

morph-glass rounded-squircle

Surface + shape utilities compose.

Layout utilities

Spacing, flex, grid, and sizing use short names:

d-flex f-col gap-3 p-4 mt-2 w-100 grid-3

Dark mode and overrides

Put theme-dark on <html> or any subtree. Recolor the whole framework by reassigning tokens — no Sass fork required.

theme-dark

This island is dark even when the page is light. The navbar moon toggles the document.

Token overrides

Change --clr-primary, --clr-bg, radii, and shadows on :root or a wrapper class.
