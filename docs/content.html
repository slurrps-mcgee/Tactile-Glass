Line height

Bootstrap lh-*: lh-1, lh-sm, lh-base, lh-lg.

lh-1 — tight unit leading for compact UI chrome.

lh-sm — maps to --line-height-tight.

lh-base — maps to --line-height-relaxed (body default).

lh-lg — maps to --line-height-loose for airy paragraphs.
